# 第十章 满贯叫牌

满贯是桥牌中很重要的一部分，相对来说也比较难掌握，
下面阐述一下满贯叫牌所遵循的原则及常见手段。

### 二、满贯对控制的要求

打满贯在赢墩已经满足的情况下，需要有足够的控制，以
防止对手抢先取走嬴墩，击败定约。打满贯的首轮控制是A和
缺门，次轮控制是K与单张。
寸千小满贯定约需要有三门以上的花色中有A, 没有A的花色
中有K。有将定约的缺门与A的作用相同，单张与K的作用相同。
对于大满贯定约需要有四门花色有A, 有将定约的缺门与
A 的作用相同，单张与K的作用相同。

### 三、探查满贯定约

叫牌判断联手牌力巳经超过了成局水平，将牌确定以后，
应该进行满贯探查。探查的方式有：扣叫控制、斯普林特、关
键张问叫和越过局的邀请等。
另外在成局水平之下的逼叫叫品，如新花帮张邀请， 2NT
重询逼叫也可以作为满贯探查的前期手段。

## 第三节 满贯试探手段

除了牌点之外，另一个满贯试探中的一个重要因素就是控
制，一些赢墩很多的牌可能因为某门花色没有控制而不能完成
满贯定约。下面是几种常见的满贯试探方法：
一扣叫
在找到将牌配合后 (8张以上），再叫新花色表示该花色至
少有第二轮控制（单缺／A/KX), 扣叫虽然很简单，但其中有一
些知识点需要提出。不是任何时候叫新花色都是扣叫。如果是
高花配合（我们用M代表配合的高花），只有高千3M的新花色
才可以认为是扣叫。如果是低花配合只有高于3NT的新花色才
可以认为是扣叫。
同时扣叫都是从最经济的花色开始，如果越过某个花色则
表示该花色没有控制，如：
