### 飞牌现行规则速查（详见文档 1，出处为代码）

| 项 | 当前值 | 说明 |
|---|---|---|
| 结构判定 | `_probe_finesse_ok`（纯条件） | 存在 G：`obj > G > 防家除 obj 外最大牌`；**确定性**，不依赖采样 |
| 进池门票 | `FINESSE_PROBE_DELTA = 0.10` | Δ = **做成率差**（非赢墩均值差）；此门票是"第二道过滤器"，Δ 之上还要过 `_probe_finesse_ok` |
| Δ 门票议题 | **已结案不改**（方案 A/B 均不采纳） | 属"已知且接受的代价"，勿重复立项 |
| 接应三层判据 | `FINESSE_COMMIT_DIE_PCT = 0.05` / `FINESSE_COMMIT_ALIVE_PCT = 0.40` | 桶内引擎最优替代牌成率 ≤0.05 → 强制接应；≥0.40 → 退让引擎；灰区走比值 |
| 比值退让 | `FINESSE_RATIO = 0.75` | 仅用于灰区兜底与启动端 D 闸 |
| 启动门控 | `FINESSE_NEC_MAKE` 0.50 / `FINESSE_NEC_MIN_RATIO` 0.50 / `FINESSE_NEC_MAKE_HIGH` 0.85 / `FINESSE_NEC_RATIO` 0.70 | 稳成线 ≥0.85 退让（引擎 top1 做成率口径） |
| 介入层结构 | `_intervene` 总入口 | 分支序：`_garrison_*`（9砸，独立）→ `_finesse_*`（飞牌）；先命中先赢 |
| 已废弃概念 | ~~跨墩续飞状态机~~（v1.77 删）、~~顶张方/非顶张方~~（v1.76 废弃，**勿再引入**） | 登记只存活**本墩** |
