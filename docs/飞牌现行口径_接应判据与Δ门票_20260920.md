## 二、教训一：桶内完胜是假信号（接应端三轮试错全回退的根因）

**B26 案**：押对世界（西）里引擎榜首 ♦A 桶内做成率 0.542——**不飞仍活**。此时"桶内完胜比"Q/A = 1.0/0.542 = 1.85，看似强制 ♦Q 完胜，实际全局期望 Q 47.4% < A 53.1%（K 在东 52.6% 概率更大 + Q 押错即死）。强制接应反而错。

**6NT 案**：押对世界（西）里 ♦A 桶内 = 0——**不飞即死**。此时桶内完胜才是真信号。

**区分判据 = 押对世界榜首桶内值是否为零**。v1.96 三层判据正是此分界的阈值化（≤0.05 强制 / ≥0.40 退让 / 灰色区维持 v1.93）。

**方法论教训**：修改接应判据前，先在两个同构反例（6NT 要强制 / B26 要退让）上验证新判据给出的方向相反，再动手。本轮 v1.94b/v1.95 三轮试错均未做此预检，全部回退。

## 三、教训二：Δ 门票骑线（**2026-09-20 用户决策：方案 A / B 均不采纳，维持现状**）

**现象**：重打 6NT 第 3 墩（南持 ♦KT432、北持 ♦AJ3、防家持 Q9876），南引小♦（2/3/4）对 Q 的探针数据：

```
[探针原始] ♦ 对象Q 引♦2  东成0.413(n218) 西成0.493(n207) Δ0.08 押西 未达标
[探针原始] ♦ 对象Q 引♦T  东成0.0(n218)   西成0.314(n207) Δ0.314 押西 达标
[探针原始] ♦ 对象Q 引♦J  东成0.372(n218) 西成0.0(n207)   Δ0.372 押东 达标  ← 对侧
[路线对决] ♦ 押东最高0.372 vs 押西最高0.314 → 淘汰押西派 → 过手给北引♦J
```

小牌 Δ=0.08 < 0.10 门票未进池 → 押西派仅剩 ♦T（0.314）应战 → 输给押东 ♦J（0.372）→ 走过手路线，未复现 v1.94 时"南直飞♦4"（当时小牌押西 0.586 > 押东 0.321）。

**计算无误的证据**：引擎混合 45.2% = (0.413×218+0.493×207)/425 精确吻合；♦T 混合 15.3% = 0.314×207/425 精确吻合。桶数据、Δ、引擎值三者同源自洽。Δ 口径（做成率差）为 v1.92 定调，自定稿后未被任何后续会话（含回退）触碰。

**根因**：Δ 是**位置敏感性**，不是**方向价值**。北持 ♦AJ 双保护（J 被 Q 盖还有 A 兜底），DD 完美收官下引小牌做成率对 Q 位置天然不敏感（东 0.413 / 西 0.493）；做成率口径又被其他临界花色（♥/♣ 均有 Δ0.04~0.07 的临界）稀释。该副牌小牌 Δ 真实区间 0.08~0.14，**骑在 0.10 阈值上，采样波动决定成败**。

**同类复发记录**：v1.92 时小牌 Δ=0.135 卡 0.15 阈值 → 降到 0.10；今日 Δ=0.08 卡 0.10。统计阈值骑在信号真实区间上必然随机翻车。

### 决策记录（2026-09-20，用户定调）

> **Δ 阈值维持 `FINESSE_PROBE_DELTA = 0.10`；进池资格维持"Δ≥阈值"。方案 A、方案 B 均不采纳，此项结案，不再作为待办问题上报。**

曾评估的两个方向（**均不采纳**，留档备查）：

- **方案 A（不采纳）**：阈值降至 0.05。治标——小牌进池后押西派 0.493 > 押东 0.372 路线对决可赢回；但下次采样 Δ 掉到 0.04 仍会卡，只是把翻车点往下挪
- **方案 B（不采纳）**：进池资格从"Δ≥阈值"换成 `_probe_finesse_ok` 结构判定，Δ 只作排序参考。改动面：`_finalize_finesse_probe` 条目收集或下游池构建，且动了 v1.92"Δ 当门票"口径

**结论口径**：Δ 门票骑线属**已知且接受的代价**——采样波动在阈值附近决定个别牌局成败，是统计量做门票的固有性质，不是待修缺陷。后续会话遇到同类现象（Δ 卡阈值导致路线选择变化）**直接按本决策归档，不重复立项、不重复试错**。

## 四、通用原则（两教训合并）

1. **确定性与统计性分工**：`_probe_finesse_ok`（纯条件、确定性）定结构资格；Δ/押桶成（采样统计量）定方向与价值。让统计量去当资格门票，就会在信号骑线时随机翻车。**注（2026-09-20 决策）**：Δ 门票问题已按"接受代价"结案不改（见 §三），本条保留为**认知原则**——将来若新增其他统计量闸门，仍应优先考虑用确定性判据定资格
2. **同构反例预检**：行为需求相反的两个案例（6NT/B26）是新判据的天然测试床，动手前先验方向
3. **交叉验证便宜且必要**：引擎混合值 = 两桶按世界数加权——一条算式即可证伪"计算改错了"的怀疑，回退诊断时应先做再怀疑代码
