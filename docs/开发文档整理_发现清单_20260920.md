## 十一、⚠️ 非文档问题：AGENTS.md 与 αμ 代码在"三态定义"上直接冲突

这是本次审计发现的**唯一一处"文档可能对、代码可能错"**的冲突，不是普通漂移，需你裁决。

**AGENTS.md（现行文本，标为必须遵守的不变量）**：
> αμ engine: `success_rate` must follow the paper's three-state definition — `OutcomeVector` distinguishes three states: useful (1/0), impossible (treated as 1), useless (treated as 0). The `success_rate` is `sum(effective_value) / n` where n = **all possible worlds** (NOT just useful worlds). The `dominates` comparison must include all worlds with impossible treated as 1. The **old implementation that skipped impossible worlds and used `useful_count` as denominator was wrong**.

**代码实际（`bridge/mcts/alpha_mu.py`，已复验）**：
- `:58-64` docstring：`useful_mask[i]=False: 该 move 在 world i 不合法（impossible），**此世界不参与 score 计算，也不参与 dominance 比较**`
- `:86-91`：`success_rate()` = `sum(useful_vals) / len(useful_vals)` —— **只对 useful 世界取平均**
- `:93-98` `worst()` 同口径；`:130-145` `dominates()` 额外要求 `self.useful_mask == other.useful_mask`
- 全文件 `effective_value` / 三态 相关标识 **0 命中**

**即：代码正是 AGENTS.md 所描述的那个"错误实现"（跳过 impossible、用 useful 口径做分母）。**

- **(a) 代码后来被改回了论文口径的反面**（那 AGENTS.md 是对的，这是个真 bug）
- **(b) AGENTS.md 记的是某次讨论的方案、从未落地**（那 AGENTS.md 是错的，应改文档）
