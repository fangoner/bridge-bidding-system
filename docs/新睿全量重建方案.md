## 二、树格式契约（复用 JF / 旧方案）

- 段间 2 空行；段首若干行 = 关键词；正文 = 平铺应叫行 或 `├/│-----` 树行
- 花色开叫 → `1X：...` 平铺；应叫总表 → `1X-1Y：...` 平铺；再叫树 → `X-Y` 段，树行
- 叫品大写 `1C~7NT`；同级用 `/`；多叫品+多链接行须兄弟拆分
- 干扰/兜底段：非结构性，fallback 原文注入，首行即关键词
- 详细契约与 loader 兼容性见 `新睿体系树格式转换方案.md` 与 `新睿体系试点转换验证报告.md`

## 三、seq 驱动挂树（已试点验证）

## 四、干扰表括号关键字策略

干扰/防守表不自动建树（已证实 OCR 跨表污染，本版 md 亦需人工逐表核对）。
- 处置：**平铺在兜底段**，段首行为括号关键字（如 `1C-(X)`、`(1H)-2C`）
- 敌我判定靠位置：敌方叫品加括号、我方叫品不加括号、pass 不参与括号
- 干扰表清单（实测，涉及章）：第2章 2-69/70/71、第3章 3-62~72、第4章 4-57~66、第5章 5-49~55、第8章 8-25~30、第9章 9-18/19、第11章 11-1~11-32
- 第 11 章防守表标题已含括号（`(1♣)-第二位置的争叫` 等），可整段作 fallback 注入，首行即关键字
