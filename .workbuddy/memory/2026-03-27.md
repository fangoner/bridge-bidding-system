Web 端无法显示已有记录，叫牌结束后也不自动保存记录。

## Web端导入422错误修复（2026-03-27 00:54）

### 问题
Web端导入记录时出现 "Request failed with status code 422" 错误。

### 根本原因
1. **hands 格式不匹配**: 导入时直接传递 `recordData.hands`，但如果是 CLI 导出的数据，hands 已经是字符串格式；如果是 Web 导出的数据，hands 可能是对象格式
2. **缺少默认值**: 某些字段（如 `bidding_sequence`, `final_contract`, `declarer`, `mode`）在旧数据中可能缺失

### 修复内容
**文件**: `web/src/App.jsx`

1. **导入时转换 hands 格式**:
   ```javascript
   const handsForImport = {}
   for (const [pos, handData] of Object.entries(recordData.hands || {})) {
     if (typeof handData === 'string') {
       handsForImport[pos] = handData
     } else if (handData && handData.display) {
       handsForImport[pos] = handData.display
     } else if (handData) {
       const { spades, hearts, diamonds, clubs } = handData
       handsForImport[pos] = `♠${spades || ''} ♥${hearts || ''} ♦${diamonds || ''} ♣${clubs || ''}`.trim()
     }
   }
   ```

2. **为所有字段提供默认值**:
   ```javascript
   bidding_sequence: recordData.bidding_sequence || '',
   final_contract: recordData.final_contract || 'Pass',
   declarer: recordData.declarer || '南',
   mode: recordData.mode || '四人叫牌',
   human_position: recordData.human_position || null,
   bid_meaning: recordData.bid_meaning || '',
   note: recordData.note || '',
   ai_bidding_history: recordData.ai_bidding_history || null
   ```
